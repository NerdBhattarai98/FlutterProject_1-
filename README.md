# Flutter Todo List

A simple and modern Todo List mobile application built with Flutter and Dart. The project focuses on providing a clean user interface for creating, managing, and tracking daily tasks.

## Overview

The Flutter Todo List is a mobile task management application developed as a practical project for learning and applying Flutter and Dart development concepts.

The application provides users with a straightforward way to organize their tasks and keep track of completed and pending activities.

## Features

- Create and manage tasks
- Mark tasks as completed
- View pending and completed tasks
- Clean and responsive user interface
- Simple task management workflow
- Cross-platform application support
