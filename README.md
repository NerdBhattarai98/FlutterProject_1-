Flutter Todo List Application

A mobile Todo List application developed using Flutter. The application provides a simple and structured interface for creating, managing, and tracking daily tasks.

Overview

This project was developed to explore the fundamentals of Flutter application development and mobile user interface design. It demonstrates the implementation of a basic task management application using Flutter and Dart.

The application allows users to manage their tasks through a straightforward and user-friendly interface.

Features
Create and manage tasks
Mark tasks as completed
View existing tasks

Getting Started
Prerequisites

Before running the project, make sure the following are installed:

Flutter SDK
Dart SDK
Android Studio or Visual Studio Code
Android Emulator or a physical device

Verify the Flutter installation with:

flutter doctor
Installation

Clone the repository:

git clone https://github.com/NerdBhattarai98/FlutterProject_1-.git

Navigate to the Flutter project:

cd FlutterProject_1-/flutterpro

Install the project dependencies:

flutter pub get

Run the application:

flutter run
Purpose

The primary purpose of this project is to gain practical experience with Flutter and Dart while developing a functional mobile application. It focuses on understanding Flutter widgets, application structure, user interaction, and basic state management.
